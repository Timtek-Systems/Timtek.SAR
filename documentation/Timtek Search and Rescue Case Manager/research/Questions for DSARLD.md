# Questions for DSARLD

_Drafted by TARS, 2026-06-14, as a companion to [[Competitive Comparison]] and [[Sanity Check Report]]. Sized to fit a single message or a one-page PDF._

---

Five questions, in priority order. Answers from anyone on the DSARLD ops side would materially shape the design of the case manager I'm building.

1. **Pilot uptake — what's the actual number?** When a case opens in a pilot's area, roughly what percentage acknowledge within the first hour? Within the first six? I'm trying to set a realistic baseline so I know what "better" looks like.

2. **Case outcomes — what's the rough split?** Of every 100 cases opened, roughly how many end as reunited / recovered / rainbow bridge / never closed (cold)? I want to make sure the system handles the actual distribution, not the optimistic one.

3. **Where do pilots drop out?** Best guess — is it at signup, in the alert noise (too many irrelevant pings), in the alert relevance (wrong geography or wrong terrain), or at the "do I actually drive out for this" moment? Each one implies a different fix.

4. **Theft vs strays vs runaways — rough proportions?** And does the team's workflow change materially when a case is a suspected theft (police liaison, public flyer suppression, microchip database contact)? I'm trying to decide whether theft is a major workflow variant or an edge case.

5. **Where does dispatch actually happen today?** The public site is a directory; the real "who's going to this one" coordination must happen somewhere — Facebook Chat, WhatsApp, an admin spreadsheet, phone tree, something else. I'd like to map the end-to-end before designing a replacement.

---

**Bonus, if there's appetite for more:**

- Has DSARLD ever evaluated D4H or another professional SAR tool? If so, what was the gating factor — price, feature gap, cultural fit?
- Does the pilot insurance require named-pilot-on-named-case records, or is it umbrella cover?
- Is there a second SAR org (Sussex SAR, Eye In The Sky, Beauty's Legacy, or any other) you'd recommend I talk to as a future tenant?

---

_Context: I'm building a multi-tenant case manager for lost-pet SAR — the gap I'm targeting is the absence of a purpose-built tool in the sector. The questions above are the small handful that public research couldn't answer for me._
