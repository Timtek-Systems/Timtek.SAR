# Timtek Search and Rescue Case Manager

Welcome to the documentation vault for the **Timtek Search and Rescue Case Manager** — a multi-user web application for coordinating search and rescue operations focused on lost pets and animals.

## About

Timtek SAR Case Manager helps search and rescue teams organise, track, and execute searches for lost animals using drone operators and ground searchers. It provides case management, team coordination, search area mapping, and operational reporting.
